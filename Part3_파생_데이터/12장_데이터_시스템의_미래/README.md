# 12장: 데이터 시스템의 미래

> [Part 3] 파생 데이터

## 📖 목차

- 데이터 통합
  - 파생 데이터에 특화된 도구의 결합
  - 일괄 처리와 스트림 처리
- 데이터베이스 언번들링
  - 데이터 저장소 기술 구성하기
  - 데이터플로 주변 애플리케이션 설계
  - 파생 상태 관찰하기
- 정확성을 목표로
  - 데이터베이스에 관한 종단 간 논증
  - 제약 조건 강제하기
  - 적시성과 무결성
  - 믿어라. 하지만 확인하라.
- 옳은 일 하기
  - 예측 분석
  - 사생활과 추적
